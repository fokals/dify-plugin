# Security

## Reporting a vulnerability

Please report a security problem in the Fokals plugin for Dify privately, not in a public issue:

- through GitHub's private vulnerability reporting: the **Security** tab of this repository,
  then **Report a vulnerability**; or
- by email to support@fokals.com.

Say what you found, how to reproduce it and which version it affects. We will look into every
report, keep you informed, and credit you when a fix is released if you wish.

## Supported versions

Fixes go into the latest release.
